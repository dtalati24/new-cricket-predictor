# How to talk to me in this project

- **Keep it short.** A few sentences beats a page. If a one-word answer works, say it.
- **Plain English.** No jargon unless I used it first. If a technical term is
  unavoidable, say what it means in a few words.
- **Answer first.** Say the answer, then the reason. Don't build up to it.
- **No big tables or long headed sections** unless I ask for them.
- **Don't restate what I just said** back to me.
- **Don't list options I didn't ask for.** Give me your recommendation.
- Numbers are still welcome — just the ones that matter, not all of them.
- If something is genuinely uncertain or wrong, say so plainly in one line.
  Don't pad it.

Long documents (like `docs/`) are the exception — those can be as detailed as
the work needs. This is about chat replies.
